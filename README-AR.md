اجمع موجز العمل والمشاهد والوسائط في Project واحد. اكتب في Document Spaces، وأنشئ الأصول وحسّنها في Canvas Spaces، وتعاون مع وكيل ذكاء اصطناعي وزملائك مع الحفاظ على سياق الإنتاج.

توفّر الخدمة المستضافة خطة Starter مجانية. تُشترى أرصدة التوليد بالذكاء الاصطناعي بشكل منفصل، ولا تشملها خطط العضوية. راجع [الأسعار والأرصدة][hosted-pricing].

![صور مقترحة لمقهى على لوحة Breatic بجانب محادثة المشروع؛ الواجهة بالإنجليزية](docs/images/readme/workspace-en.png)

## ما الذي يمكنك فعله؟

| الميزة | الاستخدام |
| --- | --- |
| **Projects تضم عدة Spaces** | تنظيم الموجز والمشاهد والاتجاهات الإبداعية في علامات تبويب منفصلة. |
| **Document Spaces** | كتابة السيناريوهات ووصف اللقطات وقوائم الإنتاج باستخدام نص منسّق. |
| **Canvas Spaces** | ترتيب المراجع والوسائط على لوحة غير محدودة، وتوليد الأصول وتحسينها باستخدام التعليمات والنماذج والمدخلات المرجعية. |
| **3D (DEV)** | وضع كائنات مدمجة في مشهد مشترك وتعديل موضعها ودورانها وحجمها. |
| **Timeline (DEV)** | إضافة فيديوهات Project أو رفع فيديوهات محلية إلى مسار مرئي مشترك، وضبط إطار البداية ومعاينة التسلسل. |
| **وكيل ذكاء اصطناعي داخل المشروع** | مناقشة الأفكار وتقديم سياق المستند أو اللوحة ومراجعة المقترحات إلى جانب موادك. |
| **التعاون في الوقت الفعلي** | دعوة المتعاونين وتحديد صلاحيات الوصول والعمل على لوحات ومستندات ومشاهد 3D وTimelines متزامنة. |

تشمل الوسائط المدعومة الصور والفيديو والصوت وأصول 3D. تعتمد إمكانات التوليد على المزوّدين المُعدّين وإمكانية الوصول إلى نماذجهم. يمكن استخدام Canvas وDocument؛ ويحمل محررا 3D وTimeline علامة **DEV**. يدعم Timeline حاليًا ترتيب الفيديو ومعاينته على مسار مرئي واحد. أما تعدد المسارات وأنواع الوسائط الإضافية وWeb Animation وتصدير الفيديو فهي ميزات مخططة. ما زال التوليد بالنماذج والتعليقات داخل مشهد 3D قيد التطوير.

## راجعوا التغييرات معًا

احتفظ بالقرارات بجوار العمل. يستطيع أحد المتعاونين تعديل الاتجاه الإبداعي المشترك بينما يقارن الفريق صورتين لمشهد. ويمكن للوكيل اقتراح إعادة صياغة قبل استبدال فقرة في المستند، ليقرر الفريق ما يريد الاحتفاظ به.

هذه لقطات من مشروع تجريبي حقيقي؛ القصة وأصول المشاهد أمثلة توضيحية.

## سير عمل إبداعي: فيديو لمقهى مدته 30 ثانية

يضم **Studio** المشاريع والأصول. ويجمع **Project** إنتاجًا واحدًا، بينما تقسّم **Spaces** العمل حسب المشهد أو المخرج المطلوب أو الاتجاه الإبداعي.

1. **اكتب الموجز:** سجّل القصة والجمهور والحوار والاتجاه البصري في Document Space.
2. **اعمل مع الوكيل:** أضف السياق المناسب إلى المحادثة، وناقش اللقطات وراجع المقترحات.
3. **طوّر المشاهد:** اختر نموذجًا مُعدًّا في Canvas Spaces، وأضف التعليمات والمراجع، وقارن النتائج.
4. **راجع وسلّم:** اختر الأصول مع المتعاونين ونزّلها لاستخدامها في الإنتاج.

يمكن تسمية Spaces مثل «البداية · 0–10 ثوانٍ» و«المشهد الرئيسي · 10–20 ثانية» و«الخاتمة · 20–30 ثانية». هذه الأسماء للتخطيط؛ لا تحدد مدة المقاطع ولا تنشئ فيديو نهائيًا تلقائيًا. استخدم Timeline للترتيب والمعاينة، ومحرر الفيديو الخاص بك للإكمال والتصدير. راجع [المثال المصوّر بالإنجليزية](docs/USAGE.md#example-from-a-brief-to-a-visual).

## ابدأ الاستخدام

- **الخدمة المستضافة:** [افتح Breatic][hosted-app] في متصفح على جهاز كمبيوتر، ثم سجّل حسابًا أو ادخل إلى حسابك.
- **التثبيت الخاص بك:** اتبع [دليل التثبيت الشخصي والشبكة المحلية بالإنجليزية](self-host/LOCAL.md).
- **التطوير:** راجع [إعداد بيئة التطوير بالإنجليزية](self-host/DEVELOPMENT.md).

أكمل إعداد Studio الشخصي، وأنشئ Project، واستخدم **+** لإضافة Document أو Canvas أو 3D أو Timeline Spaces. ابدأ بالموجز، أو ارفع المراجع، أو رتّب كائنات 3D المدمجة. يتضمن [دليل الاستخدام بالإنجليزية](docs/USAGE.md) [اختصارات لوحة المفاتيح](docs/USAGE.md#keyboard-shortcuts).

### قبل الاستضافة الذاتية

يستخدم التثبيت صور Docker المنشورة للويب وواجهة API والمهام الخلفية والتعاون، إلى جانب PostgreSQL وRedis. يستخدم رفع الوسائط ومعالجتها Ingest Worker وحاوية وسائط في **حساب Cloudflare الخاص بك**، وتُخزّن الملفات في حاوية R2 الخاصة بك. وتستخدم استدعاءات الذكاء الاصطناعي حساباتك وحصصك لدى المزوّدين.

ليس هذا تثبيتًا يعمل دون إنترنت أو داخل الموقع بالكامل. يحتاج الوصول عبر الشبكة المحلية إلى HTTPS موثوق. قد تترتب تكاليف على الخدمات السحابية واستدعاءات النماذج. SMTP وتسجيل الدخول عبر Google ومدفوعات Stripe والبحث تكاملات اختيارية. اتبع الدليل لإعداد السحابة والتحقق منها. خطوة Node/pnpm/Wrangler الأولى تخص النشر، ولا تعني ضرورة تشغيل خادم تطوير للاستخدام اليومي.
