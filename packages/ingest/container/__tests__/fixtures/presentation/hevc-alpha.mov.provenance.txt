hevc-alpha.mov: HEVC with an alpha layer in QuickTime (hvc1), 160x96, 25 fps, 10 frames.
Purpose: S6d D1 alpha classification fixture (inner#1306 test plan §91 D-6). The Linux media
image has no VideoToolbox encoder, so this clip is committed instead of generated at test time.
Generated on macOS 26.6.2 with FFmpeg 7.1.1 (Homebrew):
  ffmpeg -f lavfi -i "testsrc2=s=160x96:r=25:d=0.4,format=bgra" -c:v hevc_videotoolbox -alpha_quality 0.75 -tag:v hvc1 hevc-alpha.mov
SHA-256: d6313e39f17f0cc992e0f39d4bdac69ca241454f943f2ab78c1635678b8bf973
Measured: FFmpeg 8.0.1 (the media image) decodes it as yuva420p; FFmpeg 7.1.1 decodes it as yuv420p,
and ffprobe -show_frames reports yuv420p on both.
