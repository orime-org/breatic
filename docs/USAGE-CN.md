# Breatic 使用指南

[English](USAGE.md) | **简体中文** · [产品介绍](../README-CN.md)

在桌面浏览器中使用 Breatic。使用官方在线产品时先[注册或登录](https://breatic.ai/login)；自行部署时先完成[个人与局域网指南](../self-host/LOCAL-CN.md)，开发者请使用[开发环境指南](../self-host/DEVELOPMENT-CN.md)。

## 创建第一个项目

安装完成后：

1. 在桌面浏览器中打开实例地址，注册账号并完成个人 Studio 设置。启用了邮件时，输入邮件里的 6 位验证码完成注册；未启用邮件时，保存注册后显示的恢复码。没有共用的默认密码，也没有免登录模式。开通了付费的实例上，注册表单还有一个选填的推广码，从推广者的专属链接进来时会自动填好。
2. 为要创作的内容创建项目，选择初始 Space 类型。
3. 点击项目 Space 栏中的 **+**，添加 **Document** Space，命名为“剧本与创作简报”，写下故事或需求。如果初始 Space 已选文档，直接使用它即可。
4. 按场景或创意方向添加一个或多个 **Canvas** Space，分别命名，上传参考素材或添加节点，开始创作。
5. 通过标签页切换 Space，通过 Space 列表查找、管理项目中的其他空间。使用聊天和画布工具，通过已配置的模型生成、调整资产。
6. 与允许访问该实例的协作者分享项目，并设置他们的访问权限。

Space 标签最左侧的小 loading 表示当前浏览器已知该 Space 有工作正在进行，包含已反映到本端的协作者任务。切到其他 Space 后，原标签继续更新；悬停忙态标签可查看完整名字和运行状态。

如果加入的是现有实例，直接使用部署者提供的地址，从注册账号开始，不需要另外部署。部署者应在邀请用户前，完成部署指南中的登录、持久化、协作、上传和生成检查。

## 在 Breatic 中工作

- **编写创作计划：** 在 Document Space 中用标题划分场景、列表记录镜头描述、待办列表跟进制作任务。选中文字进行格式调整，或使用下方的文档快捷键。
- **添加与排列内容：** 上传参考素材，或在画布空白处右键选择节点类型。拖动节点调整位置，在空白处拖拽框选区域。
- **浏览画布：** 鼠标滚轮或触控板双指滚动用于平移；双指捏合或 `Ctrl+滚轮` 用于缩放。视图工具栏提供缩放、适应窗口、网格吸附和小地图。双击空白画布不会缩放。
- **处理选中节点：** 右键节点或选区，查看复制、创建副本、分组、重命名、锁定/解锁、下载、删除等可用操作。菜单由当前选区和权限决定，并非每种节点都有所有操作。
- **生成与调整：** 选择已配置的模型，提供提示词及所需参考素材，等待任务产出后继续处理。即使应用服务健康，缺少供应商凭据或额度仍可能阻止生成。
- **和 Agent 一起做：** 在对话面板告诉 Agent 你想做什么。它会先用一张问卷问清只有你知道、它也看不到的事，比如你的角色是谁、有没有需要对齐的已有作品。外观这类取决于喜好的部分，它会按最低价设置给出两三版不同的试稿，并说明各要花多少；你选定一版后，它再安排后面的步骤。它的提议以卡片形式出现：不按卡片上的按钮就不会放置，不开始生成就不会生成。
- **给 Agent 写长期要求：** 对话面板顶部的卷轴图标（**Project 指令**）打开一段纯文本，这个 Project 里每个成员、每次对话发出的每条消息都会把它一起发给 Agent，比如用什么语言回答、保持什么风格。Owner 和 Editor 可以修改；按 **保存** 后从下一条消息起生效，保存空内容即清除；Project 有指令时图标上会显示一个小圆点。
- **看哪些对话还在回答：** 在对话列表里，Agent 还在回答的对话（不论在这个页面、另一个标签页还是你的另一台设备上），名字前的小圆点会变成一个转动的小圈，回答结束后变回圆点。
- **协作与保留工作：** 画布修改通过协作服务同步。离开前确认同步和上传已经完成；浏览器断线或任务尚未结束，不能视为内容已经保存。验收持久化时应刷新并重新打开项目。

当前 Project 已打开的 Canvas 或 Document 还有本浏览器中的修改未同步，或上传等依赖当前页面的操作仍在进行时，点击连接提示条的“刷新”会要求确认，取消会保留当前编辑。通过应用内导航离开时，可以选择“留下”或“仍然离开”。两类工作都完成后，已打开的确认框显示“可以继续”并等待选择。浏览器自身刷新或关闭时，确认框是否出现受浏览器交互条件限制。

## 在 Timeline 中编排视频

创建 Project 或新增 Space 时选择 **Timeline**。卡片上的 **DEV** 表示编辑器正在开发中。编辑器在主轨和其上方的画面轨上编排视频；预览按轨道从主轨往上叠放播放头所在位置的全部片段，每个图层按自己的位置、大小和角度摆放，多个视频按同一个时钟一起播放。左侧是预览、播放条、工具栏和轨道，右侧面板是选中片段的属性和冲突列表。

| 控件或操作 | 结果 |
| --- | --- |
| “添加素材” | 打开素材对话框，选择“Project 视频”或“本地上传”。 |
| 选择 Project 视频或点击“选择视频” | 选择已登记的 Project 视频或本地视频文件。 |
| 选择“轨道”、填写“开始帧”并点击“添加到 Timeline” | 确认轨道和整数帧位置并添加片段（主轨磁吸开启时，主轨上的开始帧决定插入位置，主轨保持首尾相接）；本地文件立即以文件名放成一个虚线片段，对话框关闭，文件在后台上传，期间 Space 标签显示转圈，上传完成后片段变成视频。轨道默认为选中片段所在轨道或主轨，开始帧默认为当前序列末尾，每次添加产生独立片段。 |
| 点击片段 | 选中片段；右侧面板显示“轨道”“开始帧”“入点（帧）”“时长（帧）”，以及所用视频按 Timeline 帧率计的帧数；网页动画副本改为显示它来自的要求。输入整数帧后按回车或离开输入框即生效。视频和网页动画副本还显示“位置与大小”：“X（px）”“Y（px）”以画布像素计，“宽度缩放（%）”“高度缩放（%）”取 1 到 10000，“旋转（°）”，以及默认开启的“锁定比例”开关，开启时改一个缩放，另一个按原比例跟着变。片段不在播放头所在帧时，这一组显示“这个片段不在当前帧。” |
| 在预览里点击图层 | 选中鼠标下最上层的图层对应的片段；点在所有图层之外取消选中。选中的图层显示带手柄的选框：在框内拖动移动它，拖方形的角等比缩放，拖边中间的圆形手柄拉伸这一边，拖上方的圆形手柄绕中心旋转。“自动吸附”开启时，图层的边和中线吸到画面的边和中线，并显示参考线。每次松手是一步撤销，拖动中按 Esc 取消。Viewer 没有选框。 |
| 拖动片段 | 改变时间位置、拖到其他轨道换轨，或拖到最上方虚线行新建轨道。拖动选中片段的两端可以裁剪。 |
| “撤销”“重做”“分割”“复制”“删除” | 撤销或重做自己的编辑，在播放头处分割选中片段，在其后紧接着放一份副本，或删除选中片段。 |
| “缩放”旁的三个开关 | “主轨磁吸”让主轨片段首尾相接，“自动吸附”（N）让拖动的边缘对齐片段边缘、播放头和第 0 帧，“联动”让主轨片段上方的片段随它移动或删除。鼠标悬停可看到开关名称。 |
| “播放”“暂停”和预览滑杆 | 播放有效编排、暂停或选择全局帧。当前位置和片段长度以“时:分:秒:帧”显示。视频缓冲期间保持当前帧，媒体就绪后继续。加载中或不可用的视频在预览右上角按轨道单独提示；“重试”只重新加载这个视频，其他图层照常播放。浏览器阻止有声播放时，播放暂停并提示“浏览器阻止了有声播放，请按播放开始。” |
| 点击“冲突”下的某一行 | 选中该片段，播放头移到片段开头，轨道区滚动到该处。每行写明片段所在轨道和冲突原因；没有冲突时显示“没有冲突”。 |
| “制作网页动画” | 打开对话框：“要求”“引擎”（DeepSeek）、“比例”（16:9、9:16 或 1:1）、“时长（秒）”和默认开启的“在播放头位置加入 Timeline”。点击“执行”开始运行；开关开启时，播放头处先放一个虚线占位副本，结果就绪后显示。用量在运行结束时结算。 |
| “执行列表” | 在右侧面板打开执行列表，分“已完成”和“进行中”。点击一行查看步骤、用量，已完成的结果可预览。“取消”停止运行，“先加入 Timeline”放入占位副本，“添加到 Timeline”每次为已完成结果加入一个新副本，失败、取消或过期后“重新执行”按原内容重新打开对话框。每个副本像视频片段一样编辑；改动或删除一个副本不影响其他副本和这条执行。 |
| 从 Space 列表重开关闭的 Space | 继续读取共享 Timeline 文档；Viewer 可以查看和预览，编辑按钮对其不可用。 |

快捷键：左右方向键将选中片段移动 1 帧（按住 Shift 移动 1 秒），主轨磁吸开启时主轨片段改为与前后片段对调；未选中片段时移动播放头；Alt+上/下换轨；Delete 或 Backspace 删除；Cmd/Ctrl+D 复制；Cmd/Ctrl+B 分割；Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做；N 开关自动吸附；拖动中按 Esc 取消。本地文件上传期间，上传者在片段属性里看到进度；上传失败时片段保留，轨道上显示“上传失败”；上传者的片段属性里写明原因，重新发送同一文件有用时提供“重试”。上传者在上传完成前离开时，片段显示“未完成”，有编辑权限的人可以删除它。预览不画这类片段，只显示一条写明轨道的提示。网页动画运行期间，即使当前显示的是其他 Space，Timeline 的 Space 标签也显示转圈。

音频图片文字编排与视频导出属于后续计划。

## 布置 3D 场景

创建项目或添加 Space 时选择 **3D**。类型依次为 Canvas、Document、3D、Timeline，默认选中 Canvas。3D 和 Timeline 卡片带有 **DEV** 标记；以此类型创建项目时，初始 Space 名称为 **3D**。

| 控件或操作 | 结果 |
| --- | --- |
| 左侧“添加”按钮 | 打开内置对象菜单，添加立方体或人形。 |
| 左侧上传箭头按钮 | 打开“导入模型”，选择 glTF、GLB 文件、文件夹或 ZIP；上传进入任务面板，所有成员都可把模型放入场景。 |
| 左侧闪光按钮 | 打开“AI 生成”：在左下角的模式按钮里选 Text to 3D 或 Image to 3D，写提示词，或从电脑、Project 填入正、左、后、右视图，调整设置后按圆形生成按钮。打开“绑定骨骼”会得到带骨骼、可以摆姿势的模型，估价会包含这一步。这次生成进入任务面板。 |
| 点击对象，Shift 点击更多对象 | 在视口或场景对象列表中选择对象；点击场景空白处清除选择。 |
| 下方中间的选中对象菜单 | 选择移动、旋转或缩放后拖动场景中的原生手柄；定位、复制副本或删除选中对象。多选对象使用等比缩放。 |
| 右侧属性面板 | 编辑单个对象的名称、以米计的位置、以度计的旋转及正数缩放。Enter 或离开字段时提交，Escape 取消草稿。带骨骼的模型多一个“姿势”区：人形角色可用站立、坐下、躺下、行走、挥手预设，另有“调整关节”开关和“恢复默认姿势”。 |
| 调整关节 | 圆点标出角色的关节。点击圆点或身体部位选中关节，再拖动上面的旋转环；拖动过程中协作者能看到关节在动。Escape 先退出调整关节，再关闭面板；选择移动、旋转或缩放也会退出。 |
| 面板关闭按钮旁的锁图标 | 锁定或解锁选中对象，Editor 可解锁其他协作者锁定的对象；副本初始为解锁状态。 |
| 右下工具条 | 从左到右为撤销、重做、属性、场景对象、任务、小地图开关。面板入口切换对应右侧浮层，浮层关闭按钮也可收起面板。 |
| 小地图 | 点击场景俯视图，移动自己的浏览相机。 |
| 任务面板 | 列出所有成员的导入和生成，新的在前，可筛选。完成的行有“放入场景”；模型已在场景里的行有“在场景中定位”，会选中全部副本并把视角移过去。失败的生成可“重试”或“移除”。要求绑定骨骼的生成会说明骨骼是否绑定成功；只有这一步失败时，模型照常交付，只按生成计费。 |
| Agent 建议 | 让 Agent 生成 3D 模型；它给出的卡片会打开当前 3D Space 的“AI 生成”对话框并填好内容。 |
| 批注 | 悬停灰色批注按钮，说明批注仍在开发中。 |

协作者共享场景对象，选区、浏览相机和撤销历史归各用户所有。Viewer 可以浏览和选择对象。多个 Editor 可同时编辑未锁定对象，选中或拖动时保持这一协作方式。切换 Space 保留当前协作文档、个人选区和撤销历史，同时释放隐藏视口；关闭 Space 标签释放该会话。上次浏览相机按账号、Project、Space 保存在当前浏览器中。

切换 Space 保留未完成的属性输入，返回后重新打开属性面板继续编辑。关闭面板、打开其他面板或浮层、改变选区会结束该输入。打开顶栏菜单后，键盘焦点进入菜单。

## 操作快捷键

Studio 页和 Project 页顶栏铃铛旁的 **?** 按钮可打开**用户手册**和**联系支持**（support@breatic.ai）；登录类页面的页脚也有这两个链接。在画布中，左侧菜单底部的**快捷键**按钮列出当前平台的全部画布快捷键和手势；Viewer 只看到对自己生效的那些。在 3D Space 中，左栏底部的**操作说明**按钮说明 3D 操作方式。

画布快捷键只在画布空间拥有键盘焦点时生效，不会替代聊天框、文本输入框或编辑器内的输入操作。编辑操作需要写权限，锁定状态或运行中的任务可能限制删除。使用画布快捷键前先点击画布。

| 操作 | macOS | Windows / Linux |
| --- | --- | --- |
| 复制选中节点 | `Cmd+C` | `Ctrl+C` |
| 粘贴支持的剪贴板内容 | `Cmd+V` | `Ctrl+V` |
| 创建选中节点的副本，不替换剪贴板 | `Cmd+D` | `Ctrl+D` |
