# README screenshot sources

The workspace and brief/result images are first-party, unmodified product screenshots from the public orime-org/home_page repository. Workspace images show the coffee-shop image-comparison tutorial; brief/result images show the Morning Ember document-to-canvas example. These are public tutorial examples, not new captures of the latest development build.

The shared-direction and agent-review images are first-party presentation cards containing real product captures from an independent example project. The shared direction was edited by an invited collaborator and observed in the owner session without a reload; the presence indicator is real. The agent review shows a proposed replacement before it was applied. The story and scene assets are illustrative, not customer evidence. No simulated UI, cursors or participants were added.
